# Release Notes — v1.0.0

## Versão

**v1.0.0**

Primeira versão integrada e estável do projeto Mini App.

## Funcionalidades

- Contador com incremento de 2 em 2.
- Função `setCount` renomeada para `updateCount`.
- Botão para incrementar o contador.
- Botão para decrementar o contador.
- Tema escuro ajustável.
- Alteração automática do texto do botão entre "Modo Escuro" e "Modo Claro".
- Alteração das cores de fundo e texto de acordo com o tema selecionado.
- Interface personalizada com a cor primária definida pela equipe.
- Integração das funcionalidades desenvolvidas pelas Equipes B e C.
- Resolução manual dos conflitos de merge entre as equipes.
